# ScreenLink

맥북과 아이패드를 **무선으로** 연결해서 아이패드를 **맥의 서브 모니터**로 쓰거나, 맥 화면을 아이패드에 **미러링**하는 앱이에요.
자세한 요구사항과 설계는 [SPEC.md](SPEC.md)에 있어요.

> 현재 버전: **v0.1 (프로토타입)**

## 지금 되는 것

| 기능 | 상태 |
|---|---|
| 같은 Wi‑Fi에서 맥 자동 검색 (Bonjour) + IP 직접 입력 | ✅ |
| 6자리 PIN 인증 | ✅ 맥에서 확인함 |
| **서브 모니터 모드**: 아이패드 크기의 가상 디스플레이를 만들어 Retina로 전송 | ✅ 맥에서 확인함 |
| **미러링 모드**: 맥 메인 화면 전송 | ✅ 맥에서 확인함 |
| H.264 하드웨어 인코딩/디코딩, 네트워크가 느릴 때 프레임 건너뛰기 | ✅ |
| 아이패드 터치 → 맥 마우스 (탭=클릭, 드래그, 길게 누르기=오른쪽 클릭, 두 손가락 스크롤) | ⚠️ 코드만 작성, 기기 테스트 필요 |
| 애플펜슬로 그리기 (누르기/끌기) | ⚠️ 코드만 작성, 기기 테스트 필요 |
| 보기 전용 모드, 세 손가락 탭으로 컨트롤 막대 열기 | ⚠️ 코드만 작성, 기기 테스트 필요 |
| fps / 비트레이트 / 왕복 지연시간 표시 | ✅ |

"맥에서 확인함"은 아이패드 대신 맥에서 같은 연결·디코딩 코드를 돌려 시험했다는 뜻이에요 (아래 [개발 도구](#개발-도구) 참고).
아이패드 화면(UIKit/SwiftUI) 코드는 Xcode가 있어야 빌드할 수 있어서 아직 실제 기기에서 돌려 보지 않았어요.

## 준비물

- 맥: macOS 14 이상
- 아이패드: iPadOS 17 이상
- 아이패드 앱 빌드용: **Xcode** (App Store에서 무료로 설치)와 Apple ID

## 1. 맥 앱 실행하기

Xcode 없이 Command Line Tools만으로 빌드할 수 있어요.

```bash
./scripts/build-mac.sh
open ~/Library/Caches/ScreenLink/build/ScreenLink.app
```

> 프로젝트가 iCloud Drive 안에 있으면 코드 서명이 실패해서, 빌드 결과물은 `~/Library/Caches/ScreenLink/build`에 만들어요.

메뉴 막대에 ScreenLink 아이콘이 생겨요. 처음 실행할 때 권한 두 가지를 허용해 주세요.
- **화면 기록**: 화면을 캡처하는 데 필요해요. 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음
- **손쉬운 사용**: 아이패드 터치로 맥을 조작하는 데 필요해요.

메뉴에서 **PIN**과 **맥의 IP 주소**를 확인할 수 있어요.

## 2. 아이패드 앱 설치하기

```bash
brew install xcodegen
xcodegen            # ScreenLink.xcodeproj 생성
open ScreenLink.xcodeproj
```

1. Xcode에서 `ScreenLinkViewer` 타깃을 선택해요.
2. **Signing & Capabilities** → Team에서 본인 Apple ID를 골라요. 무료 계정이면 앱이 7일 동안 유지돼요.
3. 아이패드를 케이블로 연결하고 실행해요. 처음 한 번은 아이패드의 설정 → 개인정보 보호 및 보안 → **개발자 모드**를 켜야 해요.

Xcode로 맥 앱을 빌드하고 싶으면 `ScreenLinkHost` 타깃을 실행하면 돼요.

## 3. 사용하기

1. 맥에서 ScreenLink를 켜 둬요.
2. 아이패드 앱의 목록에서 맥을 누르고 **모드**(서브 모니터 / 미러링)와 **PIN**을 입력해요.
3. 서브 모니터 모드에서는 맥의 시스템 설정 → 디스플레이에서 아이패드 화면의 위치를 바꿀 수 있어요.

| 아이패드 동작 | 맥에서 |
|---|---|
| 한 손가락 탭 | 클릭 (빠르게 두 번 탭하면 더블클릭) |
| 한 손가락 드래그 | 끌기 |
| 길게 누르기 | 오른쪽 클릭 |
| 두 손가락 드래그 | 스크롤 |
| 애플펜슬 | 바로 누르고 끌기 |
| 세 손가락 탭 | 컨트롤 막대 보이기/숨기기 (보기 전용, 연결 끊기) |

**연결이 안 될 때**
- 두 기기가 같은 Wi‑Fi에 연결되어 있는지 확인해 주세요.
- 학교나 회사 Wi‑Fi는 기기끼리 통신하는 것을 막는 경우가 많아요. 이럴 때는 아이폰 핫스팟에 두 기기를 함께 연결해 보세요.
- 아이패드의 설정 → 개인정보 보호 및 보안 → 로컬 네트워크에서 ScreenLink가 켜져 있는지 확인해 주세요.

## 폴더 구조

```
Shared/   두 앱이 같이 쓰는 코드: 프로토콜, TCP 연결, H.264 변환
Mac/      맥 메뉴 막대 앱: 화면 캡처, 인코딩, 가상 디스플레이, 입력 주입
iPad/     아이패드 앱: 맥 검색, 영상 표시, 터치 입력
Tests/    자체 테스트 (Xcode 없이 실행)
Tools/    probe: 아이패드 없이 맥 앱을 시험하는 클라이언트
scripts/  빌드 스크립트
project.yml  XcodeGen 프로젝트 설정
```

## 개발 도구

```bash
./scripts/build-mac.sh debug
B=~/Library/Caches/ScreenLink/build

$B/selftest     # 프로토콜, 인코딩→디코딩, TCP 왕복 테스트

# 맥 앱을 켠 상태에서 아이패드 대신 접속해 영상을 받고 디코딩해 본다
$B/probe --pin <PIN> --mode mirror --seconds 5
$B/probe --pin <PIN> --mode extend --seconds 5   # 가상 디스플레이가 잠깐 생겼다 사라짐
```

화면에 변화가 없으면 프레임을 보내지 않기 때문에, 화면이 멈춰 있으면 probe에 찍히는 fps가 낮게 나와요.

## 알려진 한계와 다음 할 일

- **암호화가 아직 없어요.** PIN으로 접속은 막지만 영상은 암호화하지 않고 보내요. 믿을 수 있는 네트워크에서만 쓰세요. (SPEC N‑06: TLS 적용 예정)
- 가상 디스플레이는 애플의 비공개 API(`CGVirtualDisplay`)를 써요. 그래서 App Store에는 올릴 수 없고, macOS 업데이트 후 동작이 바뀔 수 있어요.
- 영상은 SPEC에 적은 QUIC 대신 TCP로 보내요. 네트워크가 막히면 프레임을 건너뛰지만, 비트레이트를 자동으로 조절하는 기능은 아직 없어요.
- 아직 없는 기능: 아이패드 화면을 맥에 미러링(ReplayKit), 펜슬 필압, 키보드 입력, 연결이 끊겼을 때 자동 재연결
- 서브 모니터 모드에서 연결한 뒤 아이패드를 회전하면 화면 비율이 맞지 않아요. 회전한 방향으로 다시 연결해 주세요.
- 맥 앱을 다시 빌드하면 ad-hoc 서명이 바뀌어서 화면 기록 권한을 다시 허용해야 할 수 있어요.
